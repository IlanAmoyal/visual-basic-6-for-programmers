# Visual Basic 6 למתכנתים

המאגר מרכז את קובצי המהדורה הדיגיטלית של הספר **Visual Basic 6 למתכנתים**, מאת אילן אמויאל.

הספר מיועד למתכנתים המעוניינים להעמיק בעבודה עם Visual Basic 6. הוא מציג את סביבת הפיתוח, טפסים ופקדים, את מרכיבי השפה ונושאים נוספים הנחוצים לפיתוח ב־VB6.

הספר יכול להתאים גם למי שמתחזקים מערכות ותיקות שנכתבו ב־VB6, ממשיכים לפתח אותן או רוצים להבין את הקוד שלהן. הידע בשפה עשוי לסייע גם בכתיבת פקודות מאקרו ב־VBA, בכלים וביישומים התומכים בכך.

## קובצי הספר

קובצי הספר והחומרים הנלווים יצורפו למאגר בהמשך. לאחר הוספתם, הקישורים להורדה ולצפייה יופיעו כאן.

## זכויות יוצרים ורישיון שימוש

הספר מוגש לציבור ללא תשלום, לשימוש אישי ולמטרות לימוד. הפצתו ללא תשלום אינה מהווה ויתור על זכויות היוצרים. תנאי השימוש מפורטים בקובץ [LICENSE](LICENSE).

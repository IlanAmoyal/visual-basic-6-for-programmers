# Visual Basic 6 למתכנתים

המאגר מרכז את קובצי המהדורה הדיגיטלית של הספר **Visual Basic 6 למתכנתים**, מאת אילן אמויאל.

הספר מיועד למתכנתים המעוניינים להעמיק בעבודה עם Visual Basic 6. הוא מציג את סביבת הפיתוח, טפסים ופקדים, את מרכיבי השפה, וכן נושאים נוספים בעבודה עם Visual Basic 6.

## קובצי הספר

קובצי הספר והחומרים הנלווים יצורפו למאגר בהמשך. לאחר הוספתם, הקישורים להורדה ולצפייה יופיעו כאן.

## זכויות יוצרים ורישיון שימוש

הספר מוגש לציבור ללא תשלום, לשימוש אישי ולמטרות לימוד. אין בהפצתו ללא תשלום משום ויתור על זכויות היוצרים. תנאי השימוש מפורטים בקובץ [LICENSE](LICENSE).
